**3. מה זה Claude Code**
Claude Code הוא סוכן (Agent): מודל שפה שמקבל גישה לסביבת עבודה אמיתית ופועל בה באופן עצמאי.
- **קורא:** סורק קבצים ותיקיות ובונה לעצמו תמונה של הפרויקט לפני שהוא נוגע במשהו
- **כותב:** יוצר ועורך קבצים ישירות, בלי העתק-הדבק
- **מריץ:** מפעיל פקודות, בדיקות ושרתים, קורא את הפלט ומתקן לפיו
- **מתעד:** כל שינוי נשמר ב-git, אז כל שלב ניתן לשחזור
- **זמין בכל מקום:** טרמינל, דפדפן (claude.ai/code), אפליקציית דסקטופ ומובייל

**4. צ'אט מול סוכן**
| צ'אט (ChatGPT, Claude.ai) | Claude Code |
|---|---|
| מייצר טקסט, ואת השאר עושים ידנית | מבצע את השינוי בעצמו |
| רואה רק מה שהודבק לו | ניגש לכל הפרויקט |
| מנחש אם הקוד עובד | מריץ, רואה שגיאה ומתקן בלולאה |
| כל שיחה מתחילה מאפס | זיכרון קבוע ברמת המשתמש והפרויקט |
| המשתמש הוא המבצע | המשתמש הוא המנהל |
שורה תחתונה: "המעבר הוא מכתיבת קוד להגדרת משימות ובקרה."

**5. מודלים**
לכל משימה יש מודל שמתאים לה. ההבדל הוא בין עומק החשיבה לבין מהירות ועלות.
- **Opus:** המודל החזק ביותר. מתאים לתכנון ארכיטקטורה, לבעיות מורכבות ולמשימות ארוכות עם הרבה שלבים.
- **Sonnet:** האיזון בין איכות למהירות. מתאים לרוב עבודת הפיתוח השוטפת.
- **Haiku:** מהיר וחסכוני. מתאים לשאלות קצרות, תיקונים קטנים ומשימות חוזרות.
מחליפים מודל עם `/model` או מהתפריט באפליקציה.
כלל אצבע: מתכננים עם Opus, ומבצעים עם המודל שמתאים לגודל המשימה.

**6. Plan mode: הפרדה בין חשיבה לביצוע**
ב-Plan mode Claude חוקר, שואל ומציע תוכנית, ואסור לו לשנות אף קובץ עד שהתוכנית מאושרת.
זרימה (דיאגרמה): בקשה ← חקירת הפרויקט ← שאלות הבהרה ← תוכנית כתובה ← **אישור או תיקון** ← ביצוע ← בדיקה
מעבר בין מצבים: Shift+Tab, או בבחירה מהתפריט.

**7. למה לתכנן קודם**
- **טעויות נתפסות בשלב הזול:** לתקן משפט בתוכנית עולה פחות מלתקן עשרה קבצים
- **השאלות חושפות הנחות:** Claude שואל את מה שלא נאמר, למשל קהל יעד, סגנון או מגבלות
- **התוכנית היא חוזה:** ברור מראש מה ייבנה ומה לא
- **שליטה:** ההחלטות נשארות אצל המשתמש, והביצוע אצל Claude
[בלוק טרמינל: דוגמה מקוצרת לתוכנית אמיתית שכוללת הקשר, שלבים וקבצים]

**8. ארטיפקטים**
ארטיפקט הוא תוצר עצמאי ש-Claude בונה ומפרסם בקישור: דף, מצגת, דשבורד או כלי אינטראקטיבי.
- נפתח בכל דפדפן ובכל מכשיר, בלי התקנה ובלי שרת
- פרטי כברירת מחדל, ומשתפים רק כשרוצים
- מתעדכן באותו קישור בכל פעם שמבקשים שינוי
"המצגת הזו היא ארטיפקט. כך היא נבנתה."

**9. זיכרון**
Claude מנהל שתי שכבות זיכרון:
- **זיכרון משתמש:** מי המשתמש, איך הוא עובד ומה הוא מעדיף. נשמר בין כל השיחות.
- **זיכרון פרויקט (`CLAUDE.md`):** קובץ בתוך הפרויקט שמתאר את המבנה, את הכללים ואת "איך עובדים כאן". נטען אוטומטית בכל סשן.
אפשר לבקש ישירות: "תזכור ש..." או "תוסיף ל-CLAUDE.md ש...".

**10. להעביר את הידע מכלי AI אחרים**
מי שעבד עם ChatGPT או Gemini כבר בנה שם פרופיל עשיר, וחבל להתחיל מאפס.
1. מבקשים מהכלי הקודם: "סכם בפירוט את כל מה שאתה יודע עליי: תחומי עניין, עבודה, סגנון כתיבה והעדפות. בפורמט של רשימה."
2. עוברים על הסיכום ומסננים את מה שלא רלוונטי
3. מדביקים ל-Claude: "שמור את כל זה בזיכרון שלך"
תוצאה: Claude מתחיל מהנקודה שבה הכלים האחרים עצרו.

**11. Remote Control**
סשן שרץ על המחשב אפשר לשלוט בו מהטלפון.
- מפעילים משימה ארוכה במחשב
- ממשיכים, מאשרים ומכוונים מהאפליקציה בנייד
- מקבלים התראה כשהמשימה הסתיימה או כשנדרשת החלטה
"העבודה ממשיכה גם כשלא יושבים מול המחשב."

**12. הנדסת פרומפט: ארבעה רכיבים**
פרומפט טוב הוא תדריך, לא משאלה.
1. **רקע:** מי מבקש, באיזה הקשר, ואיזה סוג עזרה צריך
2. **מטרה ומשימה:** מה רוצים להשיג ומה בדיוק צריך לעשות
3. **פורמט:** באיזו אפליקציה או טכנולוגיה, באיזו צורה ובאיזה מבנה
4. **הגבלות:** מה אסור לשנות ומה חייב להישאר (למשל "לא להחליף את הפונט")
