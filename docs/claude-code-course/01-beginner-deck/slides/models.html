‫03 · מודלים‬

‫מודל לכל משימה‬

‫ההבדל הוא בין עומק החשיבה לבין מהירות ועלות.‬

Opus

‫החזק ביותר‬

‫תכנון ארכיטקטורה, בעיות מורכבות ומשימות ארוכות עם הרבה שלבים.‬

Sonnet

‫האיזון‬

‫איכות ומהירות יחד. מתאים לרוב עבודת הפיתוח השוטפת.‬

Haiku

‫המהיר‬

‫שאלות קצרות, תיקונים קטנים ומשימות חוזרות. מהיר וחסכוני.‬

‫החלפה: הפקודה ‎/model‎ או התפריט באפליקציה.‬

‫כלל אצבע: מתכננים עם Opus, ומבצעים עם המודל שמתאים לגודל המשימה.‬
