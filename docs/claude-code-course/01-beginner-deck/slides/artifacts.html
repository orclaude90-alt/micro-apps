‫05 · ארטיפקטים‬

‫תוצר שמתפרסם בקישור‬

‫ארטיפקט הוא תוצר עצמאי ש-Claude בונה ומפרסם: דף, מצגת, דשבורד או כלי אינטראקטיבי.‬

‫בלי התקנה‬

‫נפתח בכל דפדפן ובכל מכשיר. אין שרת לנהל.‬

‫פרטי כברירת מחדל‬

‫גלוי רק למי שיצר אותו, עד שמחליטים לשתף.‬

‫חי‬

‫כל בקשת שינוי מתעדכנת באותו קישור.‬

‫המצגת הזו היא ארטיפקט. כך היא נבנתה.‬
