‫08 · הנדסת פרומפט‬

‫פרומפט טוב הוא תדריך, לא משאלה‬

01

‫רקע‬

‫מי מבקש, באיזה הקשר, ואיזה סוג עזרה צריך.‬

02

‫מטרה ומשימה‬

‫מה רוצים להשיג, ומה בדיוק צריך לעשות.‬

03

‫פורמט‬

‫באיזו אפליקציה או טכנולוגיה, באיזו צורה ובאיזה מבנה.‬

04

‫הגבלות‬

‫מה אסור לשנות ומה חייב להישאר. למשל: ״לא להחליף את הפונט״.‬
