‫01 · מה זה‬

‫Claude Code הוא סוכן‬

‫מודל שפה שמקבל גישה לסביבת עבודה אמיתית (קבצים, טרמינל, git) ופועל בה באופן עצמאי.‬

‫קורא‬

‫סורק קבצים ותיקיות ובונה תמונה של הפרויקט לפני שהוא נוגע במשהו‬

‫כותב‬

‫יוצר ועורך קבצים ישירות, בלי העתק-הדבק‬

‫מריץ‬

‫מפעיל פקודות, בדיקות ושרתים, קורא את הפלט ומתקן לפיו‬

‫מתעד‬

‫כל שינוי נשמר ב-git, כך שכל שלב ניתן לשחזור‬

‫בכל מקום‬

‫טרמינל, דפדפן, אפליקציית דסקטופ ומובייל‬
